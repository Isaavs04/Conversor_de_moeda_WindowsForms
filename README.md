# Conversor_de_moeda_WindowsForms
Um aplicativo feito no WindowsForms com o intuito de converter qualquer valor em reais para outros cinco tipos de moeda

## ✦ Sobre
Projeto pessoal realizado para treinar lógica matemática e tratamento de erros

- **Linguagem:** C#

- **Interface:** Windows Forms (WinForms)
- **IDE:** Visual Studio


## ✦ Funcionalidades
- [x] Converter o Real para: Dólares americanos, Euros, Libras Esterlinas, Ienes e Yuan Chinês
- [x] Botão de limpar.
- [x] Botão de sair.
- [x] Tratamento de erros para valores negativos e literais.
